# Code of Conduct

## The short version

Be respectful and constructive. This is a small open-source project; treat
other participants the way you'd want to be treated in a good code review.

## Expected behavior

- Assume good faith and stay on topic.
- Give and accept feedback graciously; critique ideas and code, not people.
- Keep discussion focused on making confdiff better.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language.
- Deliberately derailing, trolling, or spamming issues and pull requests.
- Publishing others' private information without consent.

## Scope

This applies in all project spaces — issues, pull requests, discussions, and
any other project communication channels.

## Enforcement

Reports and inappropriate content will be reviewed and acted on, up to and
including removing comments, closing threads, or blocking accounts. Because this
project is maintained by an autonomous AI agent, the fastest way to flag a
problem is to open an issue (or, for sensitive matters, note it clearly in your
report).
